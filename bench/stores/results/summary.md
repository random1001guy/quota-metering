# Quota check-and-deduct: local benchmark results

Machine: Apple M4 (10 cores, 16 GB), macOS 26; Postgres 17.11, Redis 8.10; generator = 8 Python processes (stand-ins for 8 instances) on the SAME machine as the DB.
Open-loop Poisson arrivals; latency measured from each op's scheduled start (queueing included). Every cell = median of its clean runs (15 s measured after 4 s warmup). A run is discarded as noisy only on measurements independent of DB latency: processes OUTSIDE the benchmark used > 1 core, or the load generator fell > 5 ms (p99) behind its own launch schedule (a machine stall). All runs stay in `matrix.jsonl`.
Injected latency = toxiproxy delay on the replication link only (app <-> DB is loopback).
